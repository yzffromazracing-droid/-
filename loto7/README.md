# ロト7 予想ノート

ロト7（1〜37 から本数字7個＋ボーナス数字2個）の過去の当選番号を集計し、傾向をもとに次回の買い目を作るブラウザアプリです。サーバー不要で、`index.html` をブラウザで開くだけで動きます。

> ⚠️ ロトの抽選は毎回独立した無作為抽出なので、過去の当選番号から次の当選番号を当てることはできません（1等の確率は 1/10,295,472）。
> このアプリは「傾向を見ながら番号を選ぶ」ための道具です。アプリ内のバックテストで、どの考え方でも当たる数がでたらめに選んだ場合と変わらないことを確認できます。

## 機能

- **数字ごとの出方**: 1〜37 をマークシート風に並べ、直近N回の出現回数・全期間の出現回数・「何回出ていないか」を色の濃さで表示
- **買い目づくり**: 考え方を選んで1〜10口を作成
  - よく出ている数字を重視（直近N回の出現回数で重み付け）
  - しばらく出ていない数字を重視（出ていない回数で重み付け）
  - ミックス（上の2つの平均）
  - 完全ランダム
  - 「バランスを整える」をオンにすると、合計値が過去の中央80%の範囲に入り、奇数が2〜5個の組み合わせだけ残します
- **バックテスト**: 各回について「その回より前のデータだけ」で買い目を作り、実際の本数字との平均一致数を理論値 7×7÷37 ≒ 1.324 と比べます
- **コピー**: 作った買い目をテキストでコピー

## データの入れ方

初期状態では動作確認用の**サンプルデータ（無作為に生成したもの。実際の当選番号ではありません）**が入っています。
「データを入れ替える」を開き、当選番号一覧を貼り付けるか CSV ファイルを選んでください。読み込んだデータはブラウザに保存されます。

1行に「1〜37 の重複しない数字7個」が並んでいれば読み取ります。

- その直前の数字（または `第N回`）を回号、直後の2個をボーナス数字として扱います
- 日付（`2024/10/11`、`2024年10月11日`）、金額（`600,000,000円`）、見出し行は無視します
- 回号があれば古い順に並べ直し、同じ回号の重複行は1回分にまとめます
- UTF-8 と Shift_JIS の CSV に対応しています

```
回号,抽せん日,本数字1,本数字2,本数字3,本数字4,本数字5,本数字6,本数字7,ボーナス1,ボーナス2
600,2024/10/11,2,7,11,18,25,31,35,4,22
第601回	2024年10月18日	03 08 15 19 23 30 37	(01)(12)
```

正確な当選番号は、みずほ銀行の宝くじサイトなどの公式情報で確認してください。
